Ayuda

¿Qué es POST?

POST se utiliza principalmente para enviar información desde un formulario hacia el servidor.

¿Qué es GET?

GET se utiliza principalmente para solicitar y mostrar información desde el servidor.

¿Qué hace redirect()?

redirect() permite enviar al usuario hacia otra ruta de nuestra aplicación.

¿Qué es request.form?

request.form permite obtener los datos enviados mediante un formulario utilizando POST.

¿Por qué request.form queda vacío después del redirect?

Porque la redirección genera una nueva solicitud. La nueva solicitud normalmente es GET y no contiene automáticamente los datos del formulario anterior.

¿Qué significa PRG?

PRG significa:

POST → Redirect → GET

Primero enviamos los datos mediante POST, después realizamos una redirección y finalmente mostramos una página mediante GET.
